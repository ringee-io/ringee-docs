<Info>
This guide is for **developers** who want to contribute to Ringee or run it locally for development. For production use, see [Docker Compose](/installation/docker-compose).
</Info>

## Prerequisites

- **Node.js** 20 or higher
- **pnpm** 8 or higher
- **PostgreSQL** 16
- **Redis** 7

## Installation

<Steps>
<Step title="Clone the repository">

```bash
git clone https://github.com/ringee-io/ringee-app.git
cd ringee
```

</Step>

<Step title="Install dependencies">

Ringee uses a pnpm monorepo. Install all dependencies:

```bash
pnpm install
```

</Step>

<Step title="Configure environment">

```bash
cp .env.example .env
```

Edit `.env` and fill in your API keys. For local development, the database and Redis defaults should work if you have them running locally:

```env
DATABASE_URL="postgresql://ringee-user:ringee-password@localhost:5432/ringee-db-local?schema=public"
REDIS_URL="redis://localhost:6379"
REDIS_HOST="localhost"
REDIS_PORT=6379
```

See the [Configuration Reference](/configuration/reference) for all variables.

</Step>

<Step title="Set up the database">

Generate the Prisma client and run migrations:

```bash
pnpm prisma generate
pnpm prisma migrate dev
```

</Step>

<Step title="Start the development servers">

Run all services concurrently:

```bash
pnpm dev
```

`pnpm dev` runs the backend and the frontend in parallel. Start services individually with:

```bash
pnpm dev:backend        # NestJS API on :3000
pnpm dev:frontend       # Next.js on :4200
pnpm dev:orchestrator   # Temporal worker
```

</Step>
</Steps>

## Access the application

| Service | URL |
|---|---|
| Frontend | [http://localhost:4200](http://localhost:4200) |
| Backend API | [http://localhost:3000/api](http://localhost:3000/api) |
| Temporal UI | [http://localhost:8080](http://localhost:8080) |

## Project structure

```
ringee/
├── apps/
│   ├── frontend/           # Next.js app (marketing + dashboard)
│   ├── backend/            # NestJS REST API, Public API, MCP, SDK endpoints
│   ├── orchestrator/       # Temporal worker (background jobs + schedules)
│   ├── agent-cli/          # The `ringee` CLI
│   ├── browser-extension/  # Chrome extension
│   ├── chatgpt-app/        # ChatGPT App (Apps SDK MCP server)
│   ├── attio/              # Attio CRM integration
│   └── sdk-playground/     # Dialer SDK playgrounds
├── packages/
│   ├── database/           # Prisma schema, client, migrations
│   ├── platform/           # Auth, Redis, email, storage, Stripe, telephony
│   ├── services/           # Domain services
│   ├── configuration/      # Env config with startup validation
│   ├── agent/              # @ringee-io/agent — the agent layer
│   ├── dialer-core/        # Dialer engine
│   ├── dialer-ui/          # Shared dialer UI
│   ├── dialer-sdk/         # @ringee/dialer-sdk — the public browser SDK
│   └── frontend-shared/    # Shared React components and hooks
├── docker-compose.yml      # PostgreSQL, Redis, Temporal
├── docker-compose.app.yml  # Backend, orchestrator, frontend
├── .env.example
└── package.json
```

## Useful commands

```bash
# Run database migrations
pnpm prisma migrate dev

# Open Prisma Studio (database GUI)
pnpm prisma studio

# Lint all packages
pnpm lint

# Type check
pnpm type-check
```
